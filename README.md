# SPM PHARMACY
### аптека для тех, кто спит · арт-объект: frutiger aero + Y2K + vaporwave в одном окне Windows XP

> «Мы не продаём лекарства. Мы отпускаем то, чего нет в инструкциях:
> полчаса тишины, утро из чужого сна, дождь по требованию.»

Интернет-магазин фармацевтики, который не притворяется магазином.
Это **арт-объект**: глянцевое стекло, голубое небо, пузырьки, растущая
трава и двенадцать товаров с туманными названиями — для выставки,
для экрана, для 4:17. Товары — **фотореалистичные студийные фото** (WebP + PNG-fallback, 800×800
в `assets/products/` — сайт отдаёт WebP через `<picture>`, экономия ~10×; сгенерированы локально через AI: `tools/generate_ai_products.py`
на модели Stable Diffusion (Lykon/dreamshaper-8, CPU) — реальные материалы стекла,
жидкости, пластика, контактные тени; поверх вклеена читаемая этикетка SPM
(текст + штрихкод, AI текст не рисует) и лёгкий frutiger aero слой (капли росы,
блики). Запасной генератор `tools/render_products.py` (чисто программный
растровый рендер); при отсутствии WebP/PNG сайт откатывается на чистый SVG-рендер).

## Что внутри

| Слой | Что делает |
|---|---|
| `index.html` | Рабочий стол (frutiger aero) + окно приложения (Windows XP) + панель задач + корзина + модалка + зал выставки |
| `styles.css` | XP-оболочка (Luna) + три темы: aqua (frutiger aero), y2k (chrome/неон/win98), vapor (неон/VHS/глитч) |
| `themes.js` | Словарь тем: заголовки окна, адреса, статусы + декор (chrome-шары, звёзды, колонна) |
| `data.js` | Каталог: 12 «товаров» с foggy-названиями, поэмами, мета-данными + `short`/`dose` для этикеток (общий для всех тем) |
| `art.js` | Рендеры упаковок: растровые студийные фото WebP+PNG (`ART.photo` через `<picture>`, с fallback на SVG) + чистый SVG-генератор 12 типов (`feSpecularLighting` объём стекла, контактные тени, этикетки с текстом и штрихкодом) |
| `assets/products/*.{webp,png}` | 12 фотореалистичных студийных фото товаров (800×800): WebP q92 (~10× легче, основной) + PNG (fallback), AI-сгенерированы `tools/generate_ai_products.py` |
| `tools/generate_ai_products.py` | AI-генерация фото товаров (Stable Diffusion 1.5-семейство, напр. `Lykon/dreamshaper-8`, локально на CPU): `python3 tools/generate_ai_products.py` (зависимости: torch, diffusers, pillow, numpy, matplotlib). Промпты и координаты этикеток — в `tools/ai_prompts/products.py` |
| `tools/render_products.py` | Запасной программный рендер PNG-фото товаров (зависимости: pillow, numpy, matplotlib — только ради шрифтов DejaVu): `python3 tools/render_products.py` |
| `ambient.js` | Генеративный ambient-звук «туман над озером» на Web Audio (дождь, гул, капли) |
| `app.js` | XP-оболочка (окно, пуск, меню, часы), переключатель тем, роутер, корзина, эффекты, **режим выставки** |

Никаких зависимостей, никаких внешних запросов, никаких шрифтов извне.
Открывается двойным кликом по `index.html` — и работает.

## Как запустить

```bash
# вариант 1 — просто открыть файл
open index.html            # или двойной клик

# вариант 2 — локальный сервер (например, для сети выставки)
python3 -m http.server 8080
# затем на любом устройстве в той же сети: http://<ip>:8080
```

## Режимы

Сайт сделан как **рабочий стол Windows XP** поверх frutiger-aero «обоев»
(небо, солнце, облака, холм с травой, туман, пузырьки — всегда, в любой теме).
Внутри — окно приложения с title bar, вкладками, строкой меню, адресной
строкой, статусной строкой и панелью задач с часами (ходят, стартуют с 4:17).

В окне — **три вкладки-«программы»**, каждая в своей эстетике.
Товары и корзина общие, стили — разные. Тема сохраняется (localStorage).

- **🫧 Витрина · aqua (frutiger aero)** — тема по умолчанию и основной стиль:
  aqua-кнопки с глянцем, glassmorphism-карточки, градиентный заголовок.
- **💿 Архив 2000 · y2k** — тот же каталог, но в chrome и неоне: карточки —
  окошки Windows 98 с розово-синим title bar, bubble-текст с chrome-градиентом,
  chrome-шары и мерцающие звёзды на тёмном фоне, неоновая XP-оболочка.
- **🌴 Ночной сеанс · vapor** — vaporwave: synthwave-сетка перспективы,
  VHS-scanlines, glitch-заголовок с хроматической аберрацией, мраморные
  карточки с неоновой подсветкой, закатное солнце с полосами, тёмный холм
  с неоновой кромкой, вместо пузырьков — дрейфующие VHS-частицы.

Переключить тему: вкладками в окне, меню **пуск**, меню **Вид**,
строкой меню **Файл/Вид/Справка**, или двойным кликом по иконке на рабочем столе.
Кнопки окна (🗕🗖🗙) сворачивают/разворачивают/«закрывают» окно;
окно восстанавливается из панели задач.

- **Карточка товара** (`#/product/<id>`) — большое искусство, описание, поэма, покупка.
- **Манифест** (`#/about`) — текст арт-объекта.
- **Режим выставки** (`#/exhibit`) — полноэкранный attract mode: тёмный зал,
  товар парит посередине, каждые 6 секунд сменяется экспонат, идут пузырьки.
  Один клик — выход. Звук включается кнопкой 🔊 в трее панели задач (по первому
  жесту, как того требует приличие браузеров).
- **Корзина** — выдвижная панель (кнопка на панели задач); «оплата» —
  кнопка «набрать росу». Оплата принимается только сном.

## Валюта

**Росинка** (`рос.`). Курс: одна росинка = одна капля, собранная в 4:17.

## Концепция названий

Названия товаров — намеренно foggy: «Роса № 09 «До зари»», «Ампула «Туман
над озером»», «Мазь «Воспоминание о поликлинике»», «Коробка «Тишина» (издание
роскошное)». Каждое описание — короткая поэма, каждая карточка — музейный
этикет: *объём / актив / принимать*.

## Для выставки

1. Открыть на большом экране в полноэкранном режиме (F11).
2. Нажать **режим выставки** (меню пуск → «Режим выставки», или Вид → Режим выставки) — экран станет тёмным залом с парящими экспонатами.
3. Включить звук 🔊 в трее панели задач — в зале зазвучит локально сгенерированный дождь.
4. Публика может кликать по рабочему столу — рождаются пузырьки;
   переключать три темы — каждая «программа» в своём стиле.

Подставка рядом с экраном (текст таблички):

> **«SPM Pharmacy», 2025**
> Интернет-аптека, не являющаяся аптекой. Инсталляция о ностальгии по
> будущему, которое обещал frutiger aero: стекло, вода, голубое небо и
> вера в то, что технологии будут добрыми. 12 экспонатов, валюта — росинка.
> Срок годности не указан, потому что роса не портится.

# SPM PHARMACY
### интернет-аптека · тёмная, тихая, немного неправильная

> «Роса свежая. Доставка — ночью, пока город пуст.
> Принимаем заказы с 2007 года. Чек прилагается.»

Интернет-аптека, которая выглядит почти нормально — но иногда
чуть-чуть не так. Редкое мигание, дрожащий заголовок, статус
«загружено 11 из 12». Всё возвращается на место.
Сайт выглядит как обычный магазин в тёмной теме, только
иногда что-то едва заметно не то.

Товары — **фотореалистичные студийные фото** (WebP + PNG-fallback, 800×800
в `assets/products/` — сайт отдаёт WebP через `<picture>`, экономия ~10×; сгенерированы
локально через AI: `tools/generate_ai_products.py`
на модели Stable Diffusion (Lykon/dreamshaper-8, CPU) — реальные материалы стекла,
жидкости, пластика, контактные тени; поверх вшита читаемая этикетка SPM
(текст + штрихкод, AI текст не рисует) и лёгкий «росяной» слой (капли росы,
блики). Запасной генератор `tools/render_products.py` (чисто программный
растровый рендер); при отсутствии WebP/PNG сайт отдаётся на чистый SVG-рендер).

## Что внутри

| Слой | Что делает |
|---|---|
| `index.html` | Шапка магазина (бренд, навигация, часы, корзина) + `main` + подвал + корзина + модалка |
| `styles.css` | Тёмная тема магазина + uncanny-слой (мерцание, виньетка, «дыхание» цен) |
| `data.js` | Каталог: 12 «туманных» товаров, поэмы, мета-данные + `short`/`dose` для этикеток |
| `art.js` | Рендеры упаковок: растровые студийные фото WebP+PNG (`ART.photo` через `<picture>`, с fallback на SVG) + чистый SVG-генератор 12 типов (`feSpecularLighting` объём стекла, контактные тени, этикетки с текстом и штрихкодом) |
| `assets/products/*.{webp,png}` | 12 фотореалистичных студийных фото товаров (800×800): WebP q92 (основной) + PNG (fallback), AI-сгенерированы `tools/generate_ai_products.py` |
| `tools/generate_ai_products.py` | AI-генерация фото товаров (Stable Diffusion 1.5-семейство, напр. `Lykon/dreamshaper-8`, локально на CPU): `python3 tools/generate_ai_products.py` (зависимости: torch, diffusers, pillow, numpy, matplotlib). Промпты и координаты этикеток — в `tools/ai_prompts/products.py` |
| `tools/render_products.py` | Запасной программный рендер PNG-фото товаров (зависимости: pillow, numpy, matplotlib — только ради шрифтов DejaVu): `python3 tools/render_products.py` |
| `ambient.js` | Генеративный ambient-звук «туман над озером» на Web Audio (дождь, гул, капли) — не загружается, пока не разрешено |
| `app.js` | Роутер, корзина, карточки, uncanny-слой (редкие «неправильности», см. ниже) |

Никаких зависимостей, никаких внешних запросов, никаких шрифтов
извне. Открывается двойным кликом по `index.html` — и работает.

## Как запустить

```bash
# вариант 1 — просто открыть файл
open index.html            # или двойной клик

# вариант 2 — локальный сервер (например, чтобы раздать по сети)
python3 -m http.server 8080
# затем на любом устройстве в той же сети: http://<ip>:8080
```

## Страницы

Сайт — обычный магазин на тёмном фоне. Шапка, каталог, карточки,
корзина, подвал. Часы в шапке ходят и стартуют с 4:17 — иногда на минуту
показывают другое время.

В шапке — **три ссылки**: каталог, «о магазине», доставка.
Корзина — выдвижная панель справа; «оформить» — заказ принят,
доставка ночью, курьер позвонит за час. Оплата при получении, чек прилагается.

- **Карточка товара** (`#/product/<id>`) — большое фото, описание, поэма, покупка.
- **О магазине** (`#/about`) — страница магазина: доставка ночью, оплата и чек при получении, сертификаты, «зависшие» заказы.
- **Доставка** (`#/delivery`) — ночная доставка, курьер звонит за час, сдачи не будет.
- **Uncanny-слой** — сайт иногда слегка «не тот»: страница мерцает как старый монитор, заголовок на пиксель дрожит, цена едва заметно «дышит» и иногда на миг чужая, часы прыгают на 4:18, бренд на долю секунды «называется иначе», иногда появляется пустой тост «…», иногда страница сама прокручивается на пиксель. Ничего не ломается, всё возвращается на место. При включённом `prefers-reduced-motion` слой полностью выключен.
- **Корзина** — выдвижная панель (кнопка в шапке); «оформить» — заказ принят, доставка ночью, курьер позвонит за час. Оплата при получении, чек прилагается.

## Валюта

**Росинка** (`рос.`). Курс: одна росинка = одна капля росы.

## Концепция названий

Названия товаров — намеренно foggy: «Роса № 09 «До зари»», «Ампула «Туман над озером»», «Мазь «Воспоминание о поликлинике»», «Коробка «Тишина» (издание роское)». Каждое описание — короткая поэма, каждая карточка — музейный этикет: *объём / актив / принимать*.

## Если показывать людям

1. Открыть на большом экране в полноэкранном режиме (F11).
2. Оставить открытой витрину и уйти — ночью сайт особенно тихий. Если кто-то засидится допоздна, он заметит, что сайт иногда мигает не так, как положено. Это нормально.
3. Можно кликать по товарам — открывается карточка;
   «в корзину» и «оформить» работают как в настоящем магазине.

Текст таблички рядом с экраном:

> **«SPM Pharmacy», 2007**
> Интернет-аптека. Доставка по городу — ночью. Оплата при получении.
> 12 товаров, валюта — росинка.
> Если заказ завис — он уже в пути. Он всегда в пути.

## Лицензия

Демонстрационный проект. Не продаёт настоящие лекарства: все товары, цены и описания вымышлены.

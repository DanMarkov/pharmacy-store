# SPM Pharmacy

### интернет-аптека · работаем с 2007 года

> «Роса свежая. Доставка — ночью, пока город пуст.
> Принимаем заказы с 2007 года. Чек прилагается.»

Интернет-аптека. 12 товаров на витрине — флаконы, ампулы, мази,
пластыри, спреи, капсулы. Доставка по городу ночью, оплата при
получении, чек прилагается.

Товары — **фотореалистичные студийные фото** (WebP + PNG-fallback,
800×800 в `assets/products/` — сайт отдаёт WebP через `<picture>`,
экономия ~10×; сгенерированы локально через AI:
`tools/generate_ai_products.py` на модели Stable Diffusion
(Lykon/dreamshaper-8, CPU) — реальные материалы стекла, жидкости,
пластика, контактные тени; поверх вшита читаемая этикетка SPM
(текст + штрихкод, AI текст не рисует) и лёгкий «росяной» слой
(капли росы, блики). Запасной генератор `tools/render_products.py`
(чисто программный растровый рендер); при отсутствии WebP/PNG сайт
отдаётся на чистый SVG-рендер).

## Что внутри

| Слой | Что делает |
|---|---|
| `index.html` | Шапка магазина (бренд, навигация, часы, корзина) + `main` + подвал + корзина + модалка |
| `styles.css` | Тёмная тема магазина: шапка, каталог, карточки, корзина, подвал |
| `data.js` | Каталог: 12 товаров, описания, цены, бейджи + `short`/`dose` для этикеток |
| `art.js` | Рендеры упаковок: растровые студийные фото WebP+PNG (`ART.photo` через `<picture>`, с fallback на SVG) + чистый SVG-генератор 12 типов (feSpecularLighting, объём стекла, контактные тени, этикетки с текстом и штрихкодом) |
| `assets/products/*.{webp,png}` | 12 студийных фото товаров (800×800): WebP q92 (основной) + PNG (fallback), AI-сгенерированы `tools/generate_ai_products.py` |
| `tools/generate_ai_products.py` | AI-генерация фото товаров (Stable Diffusion 1.5-семейство, напр. `Lykon/dreamshaper-8`, локально на CPU): `python3 tools/generate_ai_products.py` (зависимости: torch, diffusers, pillow, numpy, matplotlib). Промпты и координаты этикеток — в `tools/ai_prompts/products.py` |
| `tools/render_products.py` | Запасной программный рендер PNG-фото товаров (зависимости: pillow, numpy, matplotlib — только шрифты DejaVu): `python3 tools/render_products.py` |
| `ambient.js` | Ambient-звук на Web Audio (дождь, гул, капли) — не загружается автоматически |
| `app.js` | Роутер, каталог, корзина, карточки товаров, оформление заказа |

Никаких зависимостей, никаких внешних запросов, никаких шрифтов
извне. Открывается двойным кликом по `index.html` — и работает.

## Как запустить

```bash
# вариант 1 — просто открыть файл
open index.html            # или двойной клик

# вариант 2 — локальный сервер (например, чтобы раздать по сети)
python3 -m http.server 8080
# затем на любом устройстве в той же сети: http://<ip>:8080
```

## Страницы

Сайт — обычный магазин на тёмном фоне: шапка, каталог, карточки,
корзина, подвал.

- **Каталог** (`#/`) — все товары на витрине.
- **Карточка товара** (`#/product/<id>`) — большое фото, описание, цена, покупка.
- **О магазине** (`#/about`) — страница магазина: доставка ночью, оплата и чек при получении, сертификаты.
- **Доставка** (`#/delivery`) — ночная доставка, курьер звонит за час, сдачи не будет.
- **Корзина** — выдвижная панель справа; «оформить» — заказ принят, доставка ночью, курьер позвонит за час. Оплата при получении, чек прилагается. Корзина живёт только в этой вкладке: закроете — начнёте сначала.

## Доставка и оплата

Доставка по городу — **ночью**, пока улицы пусты. Курьер позвонит
за час до приезда. Оплата при получении, чек прилагается.
Сдачи не будет — курьер не берёт наличные после полуночи.

Если заказ «завис» в корзине — не закрывайте страницу.
Он уже в пути.

## Валюта

**Росинка** (`рос.`). Курс: одна росинка = одна капля росы.
